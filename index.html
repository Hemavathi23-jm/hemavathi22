AWS Timetable Generator

AWS Lambda DynamoDB API Gateway HTML5/JS Serverless

This is a serverless web application that lets users create and generate timetables. Users add subjects and schedule them across days/times through a beautiful HTML interface. The frontend sends data to AWS API Gateway, which triggers two Lambda functions: one saves the schedule to DynamoDB, and the other retrieves it to display a formatted timetable. Everything runs on AWS Free Tier with zero cost, using only API Gateway, Lambda, and DynamoDB for a complete full-stack solution. The entire application is production-ready and can be deployed by simply opening the HTML file in a browser.
